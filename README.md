# VoteSmart

VoteSmart is an interactive civic education platform that helps users understand the Indian election system through guided learning, personalized voting assistance, quizzes, and real-time updates.

## Features
- **Guided Learning**: Interactive modules about the Indian electoral process.
- **My Voting Guide**: Personalized voter registration and preparation guide.
- **Flashcards & Quizzes**: Engaging ways to test and reinforce knowledge.
- **Real-time Updates**: Stay informed about upcoming elections and political developments.
- **AI Assistant**: Get answers to your civic questions instantly.

## Tech Stack
- React
- Vite
- Framer Motion (Animations)
- Lucide React (Icons)
